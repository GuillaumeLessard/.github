# QECTOR organization files

This repository holds the files GitHub uses across the [QECTOR organization](https://github.com/GuillaumeLessard):

- [`profile/README.md`](profile/README.md): the organization's public profile page
- [`SECURITY.md`](SECURITY.md): how to report a vulnerability privately, for repositories without their own policy
- [`SUPPORT.md`](SUPPORT.md): where to ask questions and report problems

Website: [qector.store](https://qector.store) · Research Archive: [zenodo.org/communities/id01t](https://zenodo.org/communities/id01t)
